# NullKey AI Support

NullKey AI — **The voice of your vault. The memory of your mind.**

## Get help

- **Bug report:** [open the bug report form](https://github.com/johnshorttn/nullkey-ai-android/issues/new?template=bug_report.yml)
- **Feature request:** [open the feature request form](https://github.com/johnshorttn/nullkey-ai-android/issues/new?template=feature_request.yml)
- **Security vulnerability:** [report privately](https://github.com/johnshorttn/nullkey-ai-android/security/advisories/new). Do not open a public issue for an exploitable vulnerability. If GitHub says reporting is unavailable, private vulnerability reporting still needs to be turned on under repository **Settings → Advanced Security**.
- **Security policy:** [SECURITY.md](https://github.com/johnshorttn/nullkey-ai-android/blob/rewrite/v2/SECURITY.md)
- **Longer support notes:** [SUPPORT.md](https://github.com/johnshorttn/nullkey-ai-android/blob/rewrite/v2/SUPPORT.md)
- **Beta:** [Beta program](beta.html). Play Beta enrollment is not open yet.

## Privacy when requesting support

NullKey handles unusually sensitive information. **Never post clipboard contents, passwords, authentication tokens, typed text, Vault contents, private documents, or personal information in a public GitHub issue.**

If you attach diagnostics, review them first. A useful report normally needs only:

- NullKey version and build number
- Stable or Beta release channel
- Android version
- device model
- a sanitized description of the error

Do not attach clipboard payloads or Vault contents unless you have deliberately chosen that text and removed secrets.
