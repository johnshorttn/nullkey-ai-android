# NullKey AI Support

For help with NullKey AI, use the project's GitHub support resources.

- **Report a bug:** use the Bug Report form in GitHub Issues.
- **Request a feature:** use the Feature Request form in GitHub Issues.
- **Security vulnerability:** use GitHub's private Security Advisory reporting path rather than a public issue.
- **General guidance:** see [SUPPORT.md](../SUPPORT.md).

## Privacy when requesting support

Do not post clipboard contents, passwords, authentication codes, private Vault data, typed text, recovery material, or other sensitive information in a public issue.

If NullKey provides a sanitized diagnostic report, review it before attaching it to a support request.
