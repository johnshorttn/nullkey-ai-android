# NullKey AI Beta Program

NullKey uses the release path:

**Development → Internal Testing → Beta → Production**

New feature releases are intended to reach opted-in Beta testers before Production. Production promotion requires explicit release approval rather than occurring automatically for every commit.

Beta builds may contain unfinished features or defects. Back up important user-managed data before testing prerelease builds.

Google Play Beta enrollment information will be added here when the testing track is available.
