# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's security advisory flow:

https://github.com/johnshorttn/nullkey-ai-android/security/advisories/new

Do not disclose exploitable vulnerabilities in public issues, discussions, screenshots, logs, or feature requests.

Because NullKey AI is a keyboard and clipboard/vault application, reports must minimize exposure of sensitive data. Do not submit real passwords, authentication tokens, clipboard contents, vault contents, typed text, or unrelated personal data. Use synthetic test data whenever possible.

Public bug reports are appropriate for ordinary non-security defects that can be described without exposing sensitive information.

## Supported versions

During pre-release development, security fixes target the current supported Stable/Beta release line and active release candidate. This section should be updated when public production versions are established.
