🔑 NullKey AI — Modular Clipboard Keyboard System

“The voice of your vault. The memory of your mind.”

Version: 1.2
Package: com.nullverse.nullkeyai
Build: .aab (Google Play compliant)
UI: Jetpack Compose (IME), HTML/CSS (Settings site via WebView)
Architecture: Modular MVVM + Plugin System
Status: IN DEVELOPMENT

🎯 Purpose

NullKey AI is a next-gen keyboard that combines clipboard logging, AI tools, secure vaulting, OCR, tagging, plugin systems, and custom web-based configuration into one powerful, private Android IME.

🧭 New Features (v1.2)

  • Trashcan System: Deleted clips go to Trash, auto-expire after 30 days, manually purgeable.
  • Swipe Actions: Configurable left/right swipe to Pin, Protect, Delete, or Tag clips.
  • Tags & Categories: Up to 10 editable user-defined tags. Default: Personal, Work, Coding, Temp, Links.
  • WebView Settings Panel: Full-screen web settings via assets/settings.html with collapsible UI groups.
  • Upload System: Upload custom themes (.zip) or plugins (.jar) through web settings UI.
